El problema real

SPSS tiene licencia que la universidad provincial no puede pagar. Stata también. MATLAB tampoco. R requiere una curva de aprendizaje que el investigador con dos tesis en paralelo no tiene tiempo de recorrer. Los modelos genéricos estadounidenses no tienen parámetros de suelo andino, población rural peruana, datos climáticos amazónicos ni regulaciones SENASA.

El resultado es siempre el mismo: Excel artesanal, plantilla casera, o recurrir a un consultor en EE.UU. que cobra en dólares, no conoce el contexto y entrega un instrumento que no puede defender frente a un comité peruano.

No hay herramientas web especializadas para investigadores latinoamericanos con metodología estadística declarada. Eso es el vacío. Y ese vacío es lo que trabajo.

El proceso

No necesito entender tu campo. Necesito entender tu problema estadístico.

Tú defines la pregunta de investigación, el corpus y los datos disponibles. Yo determino qué metodología es la correcta — Monte Carlo computacional si hay incertidumbre que modelar, bootstrap no paramétrico si la muestra es pequeña o heterogénea y no quieres asumir distribución normal, análisis de sensibilidad para saber qué variable mueve el resultado y cuál es ruido, corrección de Bonferroni si testeas múltiples hipótesis simultáneamente.

El instrumento resultante vive en la web, funciona en el navegador sin instalación, tiene autoría declarada, metodología trazable y URL permanente. Es citable como software de investigación.

No hay estimaciones optimistas. El diagnóstico inicial — gratuito — determina el alcance, la metodología exacta y el tiempo real de construcción.

Metodología declarada

Monte Carlo Cuando el problema tiene incertidumbre que modelar — miles de iteraciones sobre distribuciones de parámetros reales. El resultado no es un número: es un rango con probabilidad asociada.
Bootstrap Bootstrap no paramétrico para intervalos de confianza cuando la muestra es pequeña, heterogénea o culturalmente diversa y no cumple supuestos de normalidad. Sin SPSS. Sin restricciones de licencia.
Sensibilidad Análisis de sensibilidad para identificar qué variables mueven el resultado y cuáles son ruido. Separa lo que importa de lo que parece que importa.
Bonferroni Corrección de Bonferroni para control de error tipo I cuando se testean múltiples hipótesis simultáneamente. La convergencia no aparece por azar.
Latin Hypercube Latin Hypercube Sampling cuando el espacio de parámetros es multidimensional y requiere cobertura eficiente sin explotar el tiempo de cómputo.
Bondad de ajuste Tests Kolmogorov-Smirnov o Shapiro-Wilk para verificar que las distribuciones del modelo coincidan con lo que los datos reales muestran — no lo que la teoría asume.
